# 构建与部署

本章从新克隆的裸工程开始：在 PC 生成接收模型 C，通过命令行上传到 Linux 接收主机并编译，再运行 MATLAB 脚本完成发射、取回和解码。先跑通实验一的 1 kHz 单音，再按同样顺序进行实验二至五；实验五以 Martin M1 为例。

**裸工程**包含 `.slx` 模型、MATLAB 脚本、手写 C、图片和文档，不包含 `*_ert_rtw/` 生成代码、Simulink 缓存或 `build/` 可执行文件。首次运行真实接收机，需要完成下面的代码生成与编译步骤。

文中 **PC** 指运行 MATLAB 的电脑，**板上**指运行接收程序的 Linux 主机，可以是开发板，也可以是 Linux 电脑。标注 **PC / Bash** 的命令在 Linux/macOS 终端或 Windows Git Bash 中执行；不要直接粘贴到 PowerShell。MATLAB 代码在 PC 的 MATLAB 命令窗口执行。

按以下顺序操作：

1. [准备裸工程、软件和音频通路](#准备环境)。
2. [在 MATLAB 生成接收模型代码](#生成模型代码)。
3. [通过终端上传源码并在板上编译](#上传源码)。
4. [运行实验一至五的 MATLAB 收发脚本](#运行脚本)。
5. 需要界面操作时，使用[GUI 简要流程](#gui)。

修改模型后的重建与部署、PCM 回放等见本章后半部分。软件版本、接口和参数集中列在[接口与参数参考](接口与参数参考.md)，算法原理见[实验说明索引](README.md#按任务查文档)。

<a id="准备环境"></a>
## 一、准备裸工程与环境

### 1. 获取裸工程

在 **PC / Bash** 中，进入准备存放工程的目录后执行：

```bash
git clone https://github.com/padhialuo0426/portable-acoustic-sdr.git
cd portable-acoustic-sdr
```

已有仓库副本时直接使用。记下仓库的绝对路径，后面的 `YOUR_REPO_ROOT` 均替换为这个路径。首次克隆后没有生成代码和可执行文件属于正常状态。

保持 `common/` 与五个 `exp*/` 实验目录同级；Makefile 通过 `../common` 查找音频和 MAT 文件实现。实验五的 `sstv_transmit.sldd` 是发送模型的数据字典，需要与 `.slx` 一起保留。

### 2. 确认两端分工

| 位置 | 需要准备 |
|---|---|
| PC | 仓库、MATLAB 与对应模型/代码生成产品、可用音频输出 |
| 开发板 | Linux、gcc、make、ALSA 开发库、SSH 服务、可用音频输入 |
| 手动传文件 | PC 的 `ssh/scp`；上传打包示例使用 Bash、find、tar，Windows 可用 Git Bash |

MATLAB 产品和模型版本要求见[软件与版本](接口与参数参考.md#软件与版本)。板上不需安装 MATLAB 或硬件支持包。五个实验的发送脚本与 GUI 默认使用纯 MATLAB 调制，也可切换到 Simulink 发送模型；两种方式均无需生成发送 C。

在 Debian/Ubuntu/Raspberry Pi OS 的**板上终端**安装工具：

```bash
sudo apt update && sudo apt install -y build-essential libasound2-dev alsa-utils openssh-server
```

其他发行版安装对应的编译工具、ALSA 开发库、ALSA 命令行工具和 SSH 服务。确认板上 SSH 服务已启动。

### 3. 确认 SSH 可以登录

在 **PC 终端**执行：

```bash
ssh BOARD_USER@BOARD_IP
```

把 `BOARD_USER`、`BOARD_IP` 换为板子的账号和地址。预期进入板上 shell；不成功时先解决网络、SSH 服务或认证问题。后面的板上示例统一假设源码部署在 `~/portable-acoustic-sdr`。

### 4. 接好音频通路并枚举设备

可用兼容电平的电脑耳机/线路输出连接外置声卡线路输入，也可用扬声器和麦克风。先明确实际通路，关闭可能改变波形的混响、变声等效果，再从适中电平开始。

在**板上终端**执行：

```bash
arecord -l
```

例如输出包含 `card 2`、`device 0`，则后续输入设备可填 `plughw:2,0`。这是示例值，每次 USB 重插或重启后都应重新检查；`plughw` 可以处理声卡不直接支持的采样率转换。

在 PC 系统设置中确认实际播放输出。虚拟机可能通过虚拟声卡或远程桌面重定向播放，应确认声音最终到达哪一个物理接口；设备名称本身不能证明线路已接通。

<a id="生成模型代码"></a>
## 二、在 PC 生成接收模型代码

发送 GUI 与脚本默认使用 MATLAB 调制，可选择直接仿真发送模型；两种方式均无需生成发送 C。以下代码生成流程针对接收端。

新克隆的仓库不含 `*_ert_rtw/`。真实接收模型构建前，必须为所用实验生成一次 C；`make MOCK=1` 只能检查运行时管线，不能代替这一步。

### 1. 在 MATLAB 命令窗口生成

1. 在 MATLAB 中设置仓库根目录，并选定一组实验目录与模型名。
2. 切换到实验目录，生成代码：

```matlab
R = 'YOUR_REPO_ROOT';
expDir = 'exp1_single_freq';
mdl = 'single_fre_rev';
cd(fullfile(R, expDir));
setup_paths
load_system(mdl);
set_param(mdl, 'SystemTargetFile', 'ert.tlc');
set_param(mdl, 'HardwareBoard', 'None');
set_param(mdl, 'TargetLang', 'C');
set_param(mdl, 'GenCodeOnly', 'on');
set_param(mdl, 'GenerateSampleERTMain', 'off');
set_param(mdl, 'MatFileLogging', 'off');
set_param(mdl, 'Toolchain', 'Automatically locate an installed toolchain');
set_param(mdl, 'CodeInterfacePackaging', 'Nonreusable function');
set_param(mdl, 'RootIOFormat', 'Part of model data structure');
slbuild(mdl);
assert(isfile(fullfile([mdl '_ert_rtw'], [mdl '.h'])));
assert(isfile(fullfile([mdl '_ert_rtw'], [mdl '.c'])));
```

`YOUR_REPO_ROOT` 替换为 PC 上仓库的绝对路径。`expDir` 与 `mdl` 必须配对：

| 实验 | expDir | mdl |
|---|---|---|
| 一 | `exp1_single_freq` | `single_fre_rev` |
| 二 | `exp2_dpsk` | `dpsk_receive` |
| 三 | `exp3_chirp` | `chirp_rev_detect` |
| 四 | `exp4_v22bis` | `v22_receive` |
| 五 | `exp5_sstv` | `sstv_receive` |

预期生成当前实验目录下的 `<模型名>_ert_rtw/`，末尾断言不报错。若配置过全局代码生成文件夹，应先将其恢复为当前目录，避免生成到别处后上传旧文件。输出 `models already up to date` 表示复用了已有结果；需要强制重生成时，将上面的构建调用改为 `slbuild(mdl,'ForceTopModelBuild',true)`。

### 2. 用 Simulink 界面生成（可选）

1. 将 MATLAB 当前文件夹切到实验目录，打开对应 `.slx`。
2. 在 **APPS → Embedded Coder** 中进入代码生成界面，按 `Ctrl+E` 检查配置。
3. 对齐下表后，按 `Ctrl+B` 生成代码，确认实验目录出现生成头文件。

| 配置项 | 值或要求 |
|---|---|
| System target file | `ert.tlc` |
| Hardware board | `None` |
| Language / Generate code only | `C` / 开启 |
| Generate an example main program | 关闭，入口由板上 `src/main.c` 提供 |
| MAT-file logging | 关闭，文件由板级 `mat_sink.c` 写入 |
| Toolchain | `Automatically locate an installed toolchain` |
| Code interface packaging | `Nonreusable function` |
| Root-level I/O | `Part of model data structure`，保持 `_U/_Y` 接口 |
| 仓库模型的硬件类型 | `ARM Compatible` → `ARM Cortex-A (64-bit)` |

生成 C 与编译可执行文件是两个阶段：以上步骤不调用 PC 的 C 编译器，随后在板上用 gcc 编译。换目标架构时，要核对硬件数据类型和生成接口，再验证运行结果，不能只凭编译成功判断兼容。版本限制见[软件与版本](接口与参数参考.md#软件与版本)。

<a id="上传源码"></a>
## 三、通过终端上传与编译

以下示例先部署实验一；切换实验时，重新完成上一节代码生成，再修改 `SDR_EXP` 并重复本节。保持 `common/` 与实验目录同级，因为 Makefile 使用 `../common`。

### 1. 在 PC 打包并上传

先确认实验目录中存在上一节生成的模型 `.c/.h`，再在 **PC / Bash** 执行：

```bash
cd "YOUR_REPO_ROOT"
SDR_EXP=exp1_single_freq
SDR_BOARD='BOARD_USER@BOARD_IP'
SDR_ARCHIVE=$(mktemp)
find common "$SDR_EXP" \
  -type f \( -name '*.c' -o -name '*.h' -o -name Makefile \) \
  \( -not -path '*/slprj/*' -o -path '*/slprj/ert/_sharedutils/*' \) -print0 \
  | tar --null -czf "$SDR_ARCHIVE" -T -
tar -tzf "$SDR_ARCHIVE"
scp "$SDR_ARCHIVE" "$SDR_BOARD:~/sdr-source.tgz"
```

替换 `YOUR_REPO_ROOT`、`BOARD_USER` 和 `BOARD_IP`。包内应有 `common/include/`、`common/src/`、实验 `Makefile`、`src/` 和生成目录；存在 `slprj/ert/_sharedutils/` 时也必须包含其中源码。图片、`.m/.slx` 留在 PC。

### 2. 在板上解压源码

在**板上终端**先检查归档，再解压：

```bash
tar -tzf ~/sdr-source.tgz
mkdir -p ~/portable-acoustic-sdr
tar -xzf ~/sdr-source.tgz -C ~/portable-acoustic-sdr
```

首次部署可以直接解压；**更新已有模型时**，先按[重新部署](#重新部署)处理旧生成目录，再解压。tar 会覆盖同名文件，但不会删除本次不再生成的旧 `.c`，残留文件可能被 Makefile 一起编入。

### 3. 在板上编译真实接收机

在**板上终端**执行：

```bash
cd ~/portable-acoustic-sdr/exp1_single_freq
make clean && make MODEL=real AUDIO=alsa
```

预期最后一行包含 `build/sdr_rx` 和 `[MODEL=real AUDIO=alsa]`。编译失败时先解决错误，不继续启动旧可执行文件。

其他实验的目录和可执行文件如下，均使用 `make clean && make MODEL=real AUDIO=alsa` 编译：

| 实验 | 板上目录 | 编译结果 |
|---|---|---|
| 一 | `~/portable-acoustic-sdr/exp1_single_freq` | `build/sdr_rx` |
| 二 | `~/portable-acoustic-sdr/exp2_dpsk` | `build/dpsk_rx` |
| 三 | `~/portable-acoustic-sdr/exp3_chirp` | `build/chirp_rx` |
| 四 | `~/portable-acoustic-sdr/exp4_v22bis` | `build/v22_rx` |
| 五 | `~/portable-acoustic-sdr/exp5_sstv` | `build/sstv_rx` |

<a id="运行脚本"></a>
## 四、运行 MATLAB 收发脚本

下面使用纯 MATLAB 发送机：实验一至四保持发送脚本中的 `TX_BACKEND='matlab'`，实验五使用默认参数。所有命令按“准备发射端 → 启动板上采集 → PC 播放 → 等待结束 → 取回 → 解码”的顺序执行。

提前打开 PC 的 MATLAB 和终端、板上的终端，并准备好发射命令。`-t` 是包含手动切换时间的整个采集窗口；错过播放时机时重新采集。接收和下载会覆盖同名旧结果，需要保留时先另存。

后面的 `R` 沿用第二节设置的仓库路径；重新打开 MATLAB 后先执行 `R='YOUR_REPO_ROOT';` 并替换实际路径。`BOARD_USER`、`BOARD_IP` 和 `plughw:2,0` 均按第一节的实际环境填写。

<a id="实验一"></a>
### 实验一：从单音到频谱

#### 1. 确认接收机已就绪

按[生成模型代码](#生成模型代码)选择 `exp1_single_freq` / `single_fre_rev`，在 PC 生成 C；再按[上传源码](#上传源码)上传并编译。完成后，板上应有 `exp1_single_freq/build/sdr_rx`，构建末行显示 `MODEL=real AUDIO=alsa`。

#### 2. 准备 PC 发射端

在 **MATLAB 命令窗口**执行路径设置，暂不播放：

```matlab
R = 'YOUR_REPO_ROOT';
cd(fullfile(R, 'exp1_single_freq'));
setup_paths
```

`YOUR_REPO_ROOT` 替换为 PC 上仓库的绝对路径。以后切换实验也先切到对应目录，避免调用其他实验的同名 `gui`。

#### 3. 先启动板上采集

在**板上终端**执行，设备号按前一步查询结果替换：

```bash
cd ~/portable-acoustic-sdr/exp1_single_freq
./build/sdr_rx -d plughw:2,0 -t 8 -r raw.mat
```

看到接收机启动日志后，立即进入下一步。8 秒是本例的整个采集窗口，包含切换到 MATLAB 所花的时间；若未及时播放，就重新采集。

#### 4. 在 PC 播放

在已准备好的 **MATLAB 命令窗口**执行：

```matlab
single_fre_emit
```

脚本播放约 1 秒的 1 kHz 信号，并显示发送波形。它使用系统默认输出，播放增益与 GUI 设置独立。

#### 5. 等待采集结束并取回文件

板上接收机正常退出后，在 **PC / Bash** 执行：

```bash
cd "YOUR_REPO_ROOT/exp1_single_freq"
scp BOARD_USER@BOARD_IP:~/portable-acoustic-sdr/exp1_single_freq/single_f.mat .
scp BOARD_USER@BOARD_IP:~/portable-acoustic-sdr/exp1_single_freq/single_f2.mat .
scp BOARD_USER@BOARD_IP:~/portable-acoustic-sdr/exp1_single_freq/raw.mat .
```

替换仓库路径、账号和地址。接收和下载都会覆盖同名旧结果，需要保留时先另存到独立目录。

#### 6. 查看时域和频谱

回到实验一的 **MATLAB 命令窗口**：

```matlab
spectrum('single_f.mat', 'toFileData');
spectrum('raw.mat', 'rawAudio');
```

预期打印的主峰接近 1000 Hz。对比滤波输出与未滤波波形，检查是否削顶、静音或出现断点。若不符合，先按[电平与路由排查](Q&A.md#电平与路由)检查输入输出，暂不切换到复杂调制。

<a id="实验二"></a>
### 实验二：发送 DPSK 图片

1. 按[构建与部署](#生成模型代码)生成并部署 `exp2_dpsk` / `dpsk_receive`，确认使用真实模型和 ALSA 后端。
2. 在 PC 把 MATLAB 当前目录切到 `exp2_dpsk`，运行 `setup_paths`。确认 `dpsk_emit.m` 和 `dpsk_rev.m` 顶部的 `img_name` 都为默认 `ren512b.bmp`。

```matlab
cd(fullfile(R, 'exp2_dpsk'));
setup_paths
```

3. 在板上启动采集：

```bash
cd ~/portable-acoustic-sdr/exp2_dpsk
./build/dpsk_rx -d plughw:2,0 -t 13
```

4. 看到启动日志后，立即在 **MATLAB** 执行：

```matlab
dpsk_emit
```

默认图片发送约 6.5 秒，脚本在 PC 实验目录保存 `info_all.mat`，供后续 BER 对照。

5. 等接收正常结束，在 **PC / Bash** 下载：

```bash
cd "YOUR_REPO_ROOT/exp2_dpsk"
scp BOARD_USER@BOARD_IP:~/portable-acoustic-sdr/exp2_dpsk/dpsk5.mat .
```

6. 在 **MATLAB** 执行：

```matlab
dpsk_rev
```

预期找到图片帧、显示点阵和 BER。BER=0 表示本次像素完全一致，非零值表示存在误码；找不到帧时按[帧同步排查](Q&A.md#帧同步)检查。更换图片后要保持发射、解码设置和 `info_all.mat` 对应，并按发射脚本提示增加采集时间。

4. 看到启动日志后，立即在 **MATLAB** 执行：

```matlab
bok_emit
```

默认图片发送 18.3 秒。不要在发送结束前停止采集，帧尾也参与同步。

5. 接收结束后，在 **PC / Bash** 下载：

```bash
cd "YOUR_REPO_ROOT/exp3_chirp"

```

预期输出点阵和 BER。换为 `lzu2048b.bmp` 时，波形时长增至 210.3 秒，采集窗口至少按脚本建议的 217 秒设置。

<a id="实验四"></a>
### 实验四：发送 QPSK / 16-QAM 图片

1. 生成并部署 `exp4_v22bis` / `v22_receive`。日常使用现有 `.slx` 即可；只有修改模型源文件时才需运行 `build_model`。
2. 在 PC 切到 `exp4_v22bis`，运行 `setup_paths`。确认 `v22_emit.m` 与 `v22_rev.m` 顶部均为 `img_name='ren512b.bmp'`、`RATE=2400`。

```matlab
cd(fullfile(R, 'exp4_v22bis'));
setup_paths
```

3. 在板上执行：

```bash
cd ~/portable-acoustic-sdr/exp4_v22bis
./build/v22_rx -b 2400 -d plughw:2,0 -t 7
```

4. 看到启动日志后，立即在 **MATLAB** 执行：

```matlab
v22_emit
```

默认有效波形约 1.11 秒，包含协议前导、数据、后导与滤波拖尾；手动脚本播放时另加 1 秒起始静默和 0.3 秒尾部静默。脚本也保存 `v22_tx.raw/.wav`，可用于后续离线回放。

5. 接收正常结束后，在 **PC / Bash** 下载：

```bash
cd "YOUR_REPO_ROOT/exp4_v22bis"
scp BOARD_USER@BOARD_IP:~/portable-acoustic-sdr/exp4_v22bis/v22sym.mat .
```

6. 在 **MATLAB** 执行：

```matlab
v22_rev
```

预期首尾 m 序列定位成功、找到通过 FCS 的图片帧，显示还原点阵、实验 BER 和星座。收发两端应选择相同图片；FCS 失败而 m 序列仍可定位时，会显示实验 BER 和明确标注的本次对照点阵。默认 16-QAM 应能分辨 16 个点簇；若要观察捕获过程，可在 GUI 中切换到全部接收符号。

切到 QPSK 时，同时把两份脚本的 `RATE` 和板上 `-b` 改为 `1200`。GUI 会把所选速率传给板上程序，手动流程需要自己保持三者一致。更换图片或速率后，采用脚本或 GUI 计算的采集窗口。

<a id="实验五"></a>
### 实验五：发送 SSTV 图片

本轮先发送自带二值图，完整音频约 115.3 秒。保持音频通路稳定，避免传输中途切换设备或停止采集。

1. 生成并部署 `exp5_sstv` / `sstv_receive`，确认接收程序为 `build/sstv_rx`。
2. 在 PC 的 MATLAB 切到 `exp5_sstv`，运行 `setup_paths`。

```matlab
cd(fullfile(R, 'exp5_sstv'));
setup_paths
```

3. 在板上启动采集，设备号按实际接线替换：

```bash
cd ~/portable-acoustic-sdr/exp5_sstv
./build/sstv_rx -d plughw:2,0 -t 125
```

4. 看到启动日志后，立即在 **MATLAB** 播放默认二值图：

```matlab
sstv_emit
```

预期打印 `Martin M1：320×256，VIS 44；完整音频 115.300 秒。`，并保存 `sstv_reference.mat`、`sstv_tx.wav` 和 `sstv_tx.raw`。125 秒采集窗口留出了手动切换余量；若开始播放太晚，需重新采集。

5. 等接收程序正常退出，在 **PC / Bash** 取回：

```bash
cd "YOUR_REPO_ROOT/exp5_sstv"
scp BOARD_USER@BOARD_IP:~/portable-acoustic-sdr/exp5_sstv/sstvfreq.mat .
```

6. 在 **MATLAB** 解码：

```matlab
[result, metrics] = sstv_rev;
```

预期识别 VIS 44 并还原 256 行。参考图与本轮发送一致时，输出二值像素误差率、MAE 和 PSNR；SSTV 不带图像 FCS，收到完整图不等于像素无误。同步失败或录音截短时，按[实验五排障](Q&A.md#sstv接收)检查。

#### 选择自己的图片或保留彩色

Martin M1 支持 MATLAB 可读的 BMP、PNG、JPEG 等图片，默认二值化；关闭二值化后保留 RGB 颜色。图片等比缩放并补白到 320×256，接收质量与这次发送的处理后图片比较。

先在 **PC / MATLAB** 选择图片；此时还不要启动板上采集：

```matlab
[name, folder] = uigetfile({'*.png;*.jpg;*.jpeg;*.bmp;*.tif;*.gif','图片'});
assert(~isequal(name,0),'未选择图片');
imageFile = fullfile(folder,name);
```

然后按前面的命令启动板上采集，在 **MATLAB** 执行：

```matlab
sstv_emit(imageFile,false,true,'M1','matlab');
```

第二个参数 `false` 保留彩色，改为 `true` 则二值化；第三个参数控制是否播放。第四个参数选择模式，第五个参数选择发送实现，完整取值见[实验五参数](接口与参数参考.md#实验五参数)。其他模式的尺寸和时长不同，应调整采集窗口。

只生成文件时使用 `sstv_emit(imageFile,false,false,'M1','matlab')`，随后可做[PCM 文件回放](#文件回放)。已有录音也可运行 `sstv_wav_decode('sstv_tx.wav')` 解图，不需要发送参考。

<a id="gui"></a>
## 五、GUI 简要使用

GUI 把同一套部署、采集、播放和分析动作串起来。先按第二节生成接收模型 C，再在所选实验的 **MATLAB** 目录执行：

```matlab
setup_paths
gui
```

可直接在界面填写连接信息；也可将 `common/connection.example.json` 复制为 `common/connection.json`，填写以下三个字段，GUI 启动时自动读入：

```json
{
  "ip": "BOARD_IP",
  "username": "BOARD_USER",
  "password": "BOARD_PASSWORD"
}
```

占位符分别替换为接收主机的地址、账号和密码。修改的是 **MATLAB 所在那份工程**的文件，改后重新打开 GUI；界面中的修改不写回文件。真实配置含明文密码，已排除在 Git 和源码上传之外。

1. 点击“自检”，确认连接成功并选择实际接线的 ALSA 输入与 PC 输出设备。
2. 首次部署或接收代码更新后，点击“同步源码到板上并编译”。它执行上传与 `make`，不会替你生成模型 C。
3. 选择图片、速率或 SSTV 模式，并选择“MATLAB 脚本”或“Simulink 模型”发送机，默认 MATLAB。
4. 点击“电平校准”，调整播放幅度与系统音量，再点击“一键声学实测”。
5. 查看本次结果；需要中止时点击“中止板上采集”。

GUI 在波形生成完成后才启动采集，模型仿真耗时不会占用采集窗口。默认前导余量 1 秒、尾部余量 2 秒、播放幅度 0.8；播放幅度与系统音量相互独立，需要按实际接线校准。前导余量是采集启动后的等待，不是发送音频里的静默，也不能保证消除音频设备启动瞬态。实验四、五解码失败时会清除旧接收图，避免误把上一轮结果当作本轮结果。

## 六、修改模型后重建与部署

<a id="重新部署"></a>
### 替换生成代码并重新编译

1. 在 PC 保存模型并重新生成 C；修改了接收模块源文件时，先按本节后面的说明重建对应模型。
2. 打包新源码并确认归档完整。
3. 若用终端部署，在**板上仓库根目录**删除本次实验的旧生成代码，再解压新归档。以下只处理实验四的可再生产物：

```bash
cd ~/portable-acoustic-sdr
rm -rf -- exp4_v22bis/v22_receive_ert_rtw exp4_v22bis/slprj/ert/_sharedutils
tar -xzf ~/sdr-source.tgz -C ~/portable-acoustic-sdr
cd exp4_v22bis
make clean && make MODEL=real AUDIO=alsa
```

执行前，归档必须确实包含本次实验的生成代码。其他实验替换为对应目录；不要删除 `src/`、`common/` 或实验结果。GUI 同步已处理顶层旧生成目录替换，具体上传内容仍应与本次生成结果一致。

4. 核对模型端口和 `src/model_glue.c`。端口名称、类型或尺寸变化时，要一起更新胶水层或 `model_iface.h`，再进行文件回放和实采验证。

Makefile 会跟踪后端、模型、编译选项和头文件变化，正常本地切换不必每次清理。但跨主机复制会保留旧时间戳，重新部署时使用 `make clean && make` 能避免误用旧对象文件。指定 `BUILD=...` 时，清理也应使用同一 `BUILD`。

<a id="重建实验四模型"></a>
### 重建实验四接收模型

`build_model.m` 把 `model/*.m` 嵌入 MATLAB Function 块，并读取 `v22_params.m` 和 `model/layout.json`。保存后的 `.slx` 已包含块代码与参数，日常打开模型不需要把 `model/` 加入路径。

改动源文件后，在 **PC / MATLAB** 执行：

```matlab
R = 'YOUR_REPO_ROOT';
cd(fullfile(R, 'exp4_v22bis'));
setup_paths
build_model
```

预期重建并保存 `v22_receive.slx`，随后按[代码生成步骤](#生成模型代码)生成 C。若存在未保存的模型编辑，先保存或另存；不要通过重建丢弃仍需保留的修改。

直接在 Simulink 中编辑算法块后，应把修改回写对应 `model/*.m`；调整模块间距、注释或连线后，应同步维护 `model/layout.json`。否则下次重建会恢复源文件定义的算法与布局。需要比较两个版本时，可向 `build_model` 传入另一份 `.slx` 的完整路径，生成副本。

### 重建实验五接收模型

实验五也保留 `build_model.m`，读取 `sstv_params.m` 和 `model/*.m`。在 MATLAB 切到 `exp5_sstv` 后运行 `setup_paths; build_model`，保存新的 `sstv_receive.slx`，再按[代码生成步骤](#生成模型代码)选择该模型生成 C。日常使用已保存的模型即可；重建会采用脚本定义的布局，直接调整过模型间距时应先把位置更新到 `build_model.m`。

<a id="发送模型"></a>
### 切换与重建发送模型

实验一至四把发送脚本中的 `TX_BACKEND` 改为 `'simulink'`，实验五把 `sstv_emit` 的第五参数设为 `'simulink'`，即可改用模型生成音频，无需生成发送 C。手动流程的首次模型仿真可能比 MATLAB 调制耗时更长，应把生成时间计入采集余量，或先生成波形文件后再启动采集与播放；GUI 会自动把生成安排在采集之前。

| 实验 | 发送模型 | MATLAB 波形入口 |
|---|---|---|
| 一 | `single_fre_transmit` | `single_fre_modulate(fc,samples,amplitude,backend)` |
| 二 | `dpsk_transmit` | `dpsk_modulate(imageBits,backend)` |
| 三 | `chirp_transmit` | `chirp_modulate(imageBits,backend)` |
| 四 | `v22_transmit` | `v22_modulate(frameBits,P,backend)` |
| 五 | `sstv_transmit` | `sstv_emit(imageFile,binary,playAudio,mode,backend)` |

`backend` 默认是 `'matlab'`，改为 `'simulink'` 选择模型。例如，在实验四目录比较同一组比特的两种调制结果：

```matlab
setup_paths
P = v22_params(2400);
bits = [0 1 1 0 1 0 0 1];
x = v22_modulate(bits,P,'matlab');
y = v22_modulate(bits,P,'simulink');
assert(numel(x)==numel(y) && max(abs(x-y))<1e-12)
```

此例只比较调制波形，不播放声音；图片实验由发送入口先完成 HDLC 组帧。切换发送机比较实采结果时，保持图片、速率、输出设备、播放幅度和系统音量一致。

修改 `model/tx_*.m` 后，在对应实验目录执行 `setup_paths; build_tx_model` 更新模型。不需要执行 `slbuild`。建模脚本会重新创建发送模型；手工调整过模块间距时，先把布局保存在脚本或模型副本中，避免重建覆盖。实验五还需保留同目录的 `sstv_transmit.sldd` 总线类型字典。

发送模型和 `model/tx_*.m` 留在 PC，Linux 接收程序不调用它们。更改接收算法时仍需按照前面的流程重新生成和部署接收 C。

## 七、附加运行方式

这些流程按需要选择，不必在首次实采前全部执行。

<a id="构建模式"></a>
### 选择构建模式

下面是**互斥的用途**，不是需要依次执行的步骤。参数定义见[构建开关](接口与参数参考.md#构建开关)。

| 用途 | 构建参数 | `-d` 的含义 | 结果能说明什么 |
|---|---|---|---|
| 正式采集 | `MODEL=real AUDIO=alsa` | ALSA 设备 | 当前真实音频通路与接收链表现 |
| 文件回放 | `MODEL=real AUDIO=file` | 单声道 PCM 文件 | 给定数字输入下的真实接收算法表现 |
| 合成单音 | `MODEL=real AUDIO=null` | 不使用声卡 | 单音输入下的算法响应 |
| 管线空跑 | `MOCK=1` | 不使用声卡 | 编译、调度和 MAT 写盘是否可用 |

`MOCK=1` 强制选择桩模型与合成音频，不能用于图片解码验收。为避免产物覆盖，下面的例子用 `mktemp -d` 创建独立临时目录，程序和结果均写到该目录。

**Linux / Bash**，从实验一目录检查管线：

```bash
SDR_RUN=$(mktemp -d)
make MOCK=1 BUILD="$SDR_RUN/build" && \
  (cd "$SDR_RUN" && ./build/sdr_rx -t 1) && \
  echo "$SDR_RUN"
```

预期成功退出，并在最后打印的临时目录中产生两份单频 MAT 文件。该命令不采集声卡，也不运行真实 Simulink 算法。

<a id="文件回放"></a>
### 用 PCM 文件回放真实接收机

前提是已经生成模型 C。文件后端不依赖 ALSA，但不读取 WAV 头、不做重采样；输入格式必须为单声道有符号 16 位 PCM。工程常用的小端 Linux 平台使用 S16_LE，采样率必须与实验一致。

#### 实验二与三：用 MATLAB 生成文件并解码

先在 **PC / MATLAB** 生成 PCM 与发送真值，暂不播放。下面以实验二为例，`R` 为仓库根目录：

```matlab
cd(fullfile(R,'exp2_dpsk'));
setup_paths
img_name = 'ren512b.bmp';
waveName = 'dpsk_tx';
imdata = imread(fullfile('baseband_images',img_name));
info_all = double(imdata(:).');
x = 0.3 * dpsk_modulate(info_all,'matlab');
save('info_all.mat','info_all');
fid = fopen([waveName '.raw'],'w','ieee-le');
assert(fid>=0,'无法创建 PCM 文件');
fwrite(fid,int16(32767*x(:)),'int16');
fclose(fid);
audiowrite([waveName '.wav'],x(:),8000);
```

波形调用与发送脚本使用同一入口，包含相同的组帧、保护和滤波拖尾；这里仅保存文件。幅度取 0.3，为接收模型的两路求和留出余量，与 GUI 播放幅度独立。实验三按下表替换对应行，其余代码相同：

| 设置 | 实验二 | 实验三 |
|---|---|---|
| 实验目录 | `exp2_dpsk` | `exp3_chirp` |
| `img_name` | `ren512b.bmp` | `ren128b.bmp` |
| `waveName` | `dpsk_tx` | `chirp_tx` |
| 波形调用 | `dpsk_modulate(info_all,'matlab')` | `chirp_modulate(info_all,'matlab')` |

将生成的 `.raw` 上传到板上对应实验目录。实验二在 **PC / Bash** 执行：

```bash
cd "YOUR_REPO_ROOT/exp2_dpsk"
scp dpsk_tx.raw BOARD_USER@BOARD_IP:~/portable-acoustic-sdr/exp2_dpsk/
```

在**板上实验二目录**构建文件后端并回放：

```bash
cd ~/portable-acoustic-sdr/exp2_dpsk
SDR_EXP_DIR=$PWD
SDR_RUN=$(mktemp -d)
make MODEL=real AUDIO=file BUILD="$SDR_RUN/build" && \
  (cd "$SDR_RUN" && ./build/dpsk_rx -d "$SDR_EXP_DIR/dpsk_tx.raw") && \
  echo "$SDR_RUN"
```

实验三将目录、程序与文件名分别替换为 `exp3_chirp`、`chirp_rx` 和 `chirp_tx.raw`。两者输入采样率均为 8000 Hz，预期读到 EOF 后正常退出。

记下最后打印的临时目录，在 **PC / Bash** 下载实验二结果：

```bash
cd "YOUR_REPO_ROOT/exp2_dpsk"
scp BOARD_USER@BOARD_IP:BOARD_RUN_DIR/dpsk5.mat .
```

`BOARD_RUN_DIR` 替换为板上打印的绝对路径。实验三改为对应目录和 `chirp5.mat`。下载会覆盖同名旧结果，复制前保存需要保留的数据。

回到 PC 的对应实验目录，在 MATLAB 运行 `dpsk_rev` 或 `bok_rev`，确认脚本的 `img_name` 与本次生成时一致，并保留本次的 `info_all.mat`。预期找到帧、显示点阵与 BER=0；若不符合，先排查模型版本、图片和参数。系统可能清理临时目录，需保留的结果应另存。

#### 实验四：回放已生成的波形

`v22_emit` 在 PC 的实验目录生成 `v22_tx.raw/.wav`，同时会播放。将 `.raw` 上传到板上实验四目录，随后执行：

```bash
SDR_EXP_DIR=$PWD
SDR_RUN=$(mktemp -d)
make MODEL=real AUDIO=file BUILD="$SDR_RUN/build" && \
  (cd "$SDR_RUN" && ./build/v22_rx -b 2400 -d "$SDR_EXP_DIR/v22_tx.raw") && \
  echo "$SDR_RUN"
```

QPSK 波形改用 `-b 1200`。输入必须为 9600 Hz PCM，预期在打印的临时目录中生成 `v22sym.mat`。取回到 PC 的实验四目录后，按相同速率运行 `v22_rev`；复制前保存需要保留的旧结果。有效帧应通过 FCS，默认图片应得到 BER=0。

#### 实验五：回放 SSTV 波形

在 PC 的 MATLAB 实验五目录执行 `sstv_emit('baseband_images/ren512b.bmp',true,false)`，只生成文件而不播放。把产生的 `sstv_tx.raw` 上传到 Linux 实验五目录，再执行：

```bash
SDR_EXP_DIR=$PWD
SDR_RUN=$(mktemp -d)
make MODEL=real AUDIO=file BUILD="$SDR_RUN/build" && \
  (cd "$SDR_RUN" && ./build/sstv_rx -d "$SDR_EXP_DIR/sstv_tx.raw") && \
  echo "$SDR_RUN"
```

输入为 48000 Hz 单声道 PCM。取回 `sstvfreq.mat` 后，在 PC 实验五目录运行 `sstv_rev`；预期显示 VIS 44、256 行及二值像素误差率。它使用本次 `sstv_reference.mat` 比较图像质量，不能混用其他图片的参考文件。回到声卡采集前重新执行 `make MODEL=real AUDIO=alsa`。

<a id="直接解-wav"></a>
### 直接解实验四的 WAV

此入口不经过板上模型，适合对照排查一段录音。在 **PC / MATLAB** 执行：

```matlab
R = 'YOUR_REPO_ROOT';
cd(fullfile(R, 'exp4_v22bis'));
setup_paths
WAV = 'YOUR_RECORDING.wav';
RATE = 2400;
IMG_NAME = 'ren512b.bmp';
v22_wav_decode
```

替换 `YOUR_REPO_ROOT` 与 `YOUR_RECORDING.wav`；录音路径可为绝对路径，`RATE` 必须与发送一致。不需要真值对照时显式设 `IMG_NAME=''`，避免沿用 MATLAB 工作区中的旧值。

脚本读取 WAV 的第一声道、重采样到 9600 Hz，并定位一个突发。成功时打印 `FCS 通过` 并返回图片矩阵 `im`；失败时打印 `没有可用的图片帧`。它不自动拆分一段录音中的多次发送，离线算法与板上接收链也不逐符号等价。
