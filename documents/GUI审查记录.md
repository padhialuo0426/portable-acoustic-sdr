# GUI 审查与连接排查（2026-09-15）

## 范围和结论

审查两个 `host/gui.m` 的回调、传输、部署、采集、取消和信号处理流程，并回看从
`6b0f82c` 引入 GUI 到 `ee01c69` 的相关提交。提交说明中的验证声明只作为线索，
结论以代码和本次运行结果为准。

后续手动复现修正了最初结论：正常桌面启动 MATLAB 后，在其命令窗口运行 `gui`，
手动输入相同凭据并点自检仍失败。该桌面进程内连系统 `nc` 都失败；命令行批处理
MATLAB 则能登录。刷新 MATLAB 的两个已有局域网开关并正常重启后仍失败。
因此“保存后重启 MATLAB 即可解决”的先前结论不成立。
故障与桌面启动环境的网络访问有关，具体系统原因尚未确定。详情见 Q&A Q11。

## 验证

`tests/run_gui_regressions.m` 在临时目录给真实 GUI 源码导出测试入口，不修改生产接口。
不传环境变量可验证输入失败后的按钮恢复、错误解释、chirp 组帧和正反极性解码。
设置 `PASDR_TEST_HOST`、`PASDR_TEST_USER`、`PASDR_TEST_PASS` 后，还会验证真实树莓派上的：

- 自检和 ALSA 枚举；完整输出（含空行和大量行）及非零退出码。
- SFTP 往返、下载失败保留原文件、远端路径含空格和单引号。
- 两个实验源码上传与编译（独立 `/tmp/pasdr_regression_*` 目录）。
- 后台成功、启动失败、取消本地流程、远端进程组停止、超时停止。
- 两个生产文件的 MATLAB `checkcode`。

运行：在仓库根目录执行 `matlab -batch "addpath('tests'); run_gui_regressions"`。
密码由环境变量提供，不写入测试源码或仓库。

## 验证边界

本轮未做扬声器到麦克风的实际声学 BER 测量；硬件电平和环境噪声仍需实际校准。
Java BufferedReader 的空行返回在本机 MATLAB 为非空 Java String，EOF 才是空值，
原代码没有“空行误判 EOF”的问题；改输出读取方式是为了保持 UI 响应。

现有 chirp 波形的 `linspace(0,T,n)` 与教学脚本/模型约定一致，本轮保留。
“仅解码”仍要求选择与录制时相同的图片作为 BER 参考。现有实验环境的主机密钥校验
策略沿用原设置，并纠正了它等同于 OpenSSH `accept-new` 的错误注释。
