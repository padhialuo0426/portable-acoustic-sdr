# 接口与参数参考

本页集中列出五个实验的环境、入口、参数和数据格式。从裸工程到实采的操作流程见[构建与部署](构建与部署.md)，算法含义见[实验原理索引](README.md#按任务查文档)。

<a id="软件与版本"></a>
## 一、软件与版本

| 环节 | 软件与依赖 | 边界 |
|---|---|---|
| PC 生成接收 C | MATLAB、Simulink、Simulink Coder、Embedded Coder | 使用 `ert.tlc`；不需要板卡硬件支持包 |
| PC 发送脚本与 GUI | MATLAB 及所用函数工具箱；选择模型发送时另需 Simulink 和所用块依赖 | 默认纯 MATLAB 调制；两种方式均无需发送端 C 生成或 C 编译器 |
| 模型信号处理 | 对应版本的 DSP System Toolbox 等模型块依赖 | 由实际模型块、滤波器对象和安装版本决定 |
| 状态机及模型构建 | Stateflow 相关功能 | 实验三含 Stateflow 图；各实验的发送建模脚本及实验四、五接收建模脚本使用 MATLAB Function 块代码接口 |
| MATLAB 波形成形、重采样与滤波 | Signal Processing Toolbox 等对应函数产品 | 实验四、五使用滤波器设计与重采样；静态扫描不能替代模型许可检查 |
| 板上真实采集构建 | C 编译器、make、ALSA 开发库 | Linux 本机编译，运行时链接 ALSA 等系统库 |
| 板上文件回放或桩模型 | C 编译器、make | 不链接 ALSA；真实模型仍需要生成 C |
| GUI 连接板子 | MATLAB 中的 Java/SSH 功能、板上 SSH 服务 | 使用账号密码，不依赖系统 scp 或 ssh 密钥 |

MATLAB 产品归属可能随版本变化；`ver` 可查看安装列表，实际打开模型与代码生成的诊断还会指出缺失的块库或许可。完整生成流程以成功产出 C 为准，不能把“仅安装 MATLAB”视为全部前提。

| 模型 | 保存格式与验证边界 |
|---|---|
| 实验一至三接收模型 | 仓库模型采用 R2022a 文件格式，已在 R2025b 打开并生成代码；未以实际 R2022a 环境验证完整生成链 |
| 全部发送模型、实验四与五接收模型 | 使用 R2025b 构建；未验证导出到 R2022a 后的兼容性 |

能打开模型不等于生成接口与数值行为完全兼容。跨版本修改后的导出和验证见[版本排障](Q&A.md#模型版本)。

发送模型每步输出点数分别为 80、80、800、16；实验四发送端每步一个符号，接收端每步 60 个符号，二者处理帧长不同。

`gui_support/` 中的波形接口供 GUI 调用，也可在配置路径后手动调用。`gui.m` 仍位于实验根目录，直接运行即可。

收发脚本和 `gui.m` 在各实验的 MATLAB 当前目录直接运行。手动调用波形适配函数时运行 `addpath('gui_support')`，调用构建工具时运行 `addpath('tools')`。各实验都有同名入口，切换实验后要先切换目录。

五个 MATLAB 发送脚本和五个解码/分析脚本均按章节顺序执行，在各自的单个 `.m` 文件内实现，不调用工程辅助函数或模型。发送机和解码器也不调用彼此。直接运行发送入口即可；单频只需脚本，图片实验另需所选图片。GUI 通过“发送机”选择 MATLAB 或 Simulink，默认 MATLAB。

以下参数化波形入口负责选择分支：MATLAB 分支把输入传给独立发送文件并取回波形；模型分支独立仿真，不调用该发送文件。`common/matlab/+asdr/TxModel.m` 只服务实验一至四的模型分支，负责参数注入和音频收集；实验五模型以外部输入提供图片与模式。参数只作用于本次仿真，不保存到模型文件。

| 波形入口 | 输入与输出 |
|---|---|
| `single_fre_modulate(fc,samples,amplitude,backend)` | 频率、采样点数、幅度（默认 1）；返回实数行向量 |
| `dpsk_modulate(imageBits,backend)` | 非空 0/1 图片比特；返回包含保护与滤波拖尾的归一化音频 |
| `chirp_modulate(imageBits,backend)` | 非空 0/1 图片比特；返回逐符号 chirp 音频 |
| `[x,sym]=v22_modulate(frameBits,P,backend)` | HDLC 比特与 `v22_params` 参数；返回归一化音频及调制符号 |

以上 `backend` 均为可选参数，默认 `'matlab'`，也可传 `'simulink'`。纯 MATLAB 算法直接写在各实验的发送文件中；切换实现不会改变播放设备、幅度、采集窗口或解码规则。

实验五采用逐行模拟图像扫描，单独列出对应入口：

| 项目 | 实验五 |
|---|---|
| 实验目录 / 模型名 | `exp5_sstv` / 接收 `sstv_receive`、发送 `sstv_transmit` |
| 可执行文件 | `sstv_rx` |
| MATLAB 发射 / 分析 | `sstv_emit` / `sstv_decode` |
| 采样率 / 模型帧长 / 帧率 | 48000 Hz / 4800 点 / 10 Hz |
| 模式 / 图像尺寸 | 20 种模式；默认 Martin M1，VIS 44 / 320×256 RGB |
| 图像音调 / 行同步音调 | 1500～2300 Hz / 1200 Hz |
| 默认图片 / 处理 | `ren512b.bmp` / 二值化、等比缩放并补白 |
| 完整音频时长 | 约 115.300 秒，含 VIS 头、图像扫描和 0.1 秒尾音 |

### 图片与真值

| 实验 | 自带图片（宽×高） | 解码所需信息 |
|---|---|---|
| 二、四 | `ren512b/da512b/lan512b/ru512b/yi512b.bmp`：32×16；`lzu2048b.bmp`：64×32 | 二用 BMP 尺寸及发送真值；四从载荷恢复尺寸，BMP 仅作 BER 对照 |
| 三 | `ren128b.bmp`：16×8；`lan336.bmp`：21×16；`ren512b.bmp`：32×16；`lzu2048b.bmp`：64×32 | BMP 尺寸及发送真值 |

实验二至四的图片位于 `baseband_images/`，使用单通道二值 BMP；实验四明确检查像素为 0/1，宽、高均不超过 255。这三个实验按列优先展开像素。

实验五可选择 MATLAB `imread` 支持的任意图片，按所选模式处理图片尺寸与扫描顺序，接收端自动识别 VIS。默认二值化，关闭后保留彩色；发送参考保存到 `sstv_reference.mat`，只用于质量比较，不参与 VIS 或行同步。

实验二、三的 MATLAB 发射端写 `info_all.mat`，解码端用它计算 BER。不能混用另一轮发送的真值文件。

### 实验四参数

| 参数 | 默认值或可选值 | 用途 |
|---|---|---|
| `v22_params(rate)` | `2400`（默认）或 `1200` | 返回 GUI 与模型分支参数；独立发送脚本自带同值参数 |
| `P.bps` | 4 或 2 | 每符号比特数 |
| `P.sps` | 16 | 每符号采样点 |
| `P.beta` / `P.span` | 0.75 / 8 | RRC 滚降 / 符号跨度，共 129 抽头 |
| `P.preambleSyms` / `P.postambleSyms` | 300 / 120 | 协议前导 / 后导符号数 |
| `P.scrTaps` / `P.scrLen` | `[14 17]` / 17 | 自同步扰码器 |
| `P.syncBits` | 127 位 m 序列 | HDLC 帧前后各一段，独立定位实验 BER 窗口 |
| `P.syncGuard` | 17 bit | HDLC 与每段 m 序列之间的全 1 保护位 |
| `P.syncMaxErrors` | 25 bit | 每段标记最多容许错误数，还要求间距匹配、窗口唯一 |
| `v22_emit.m` 的 `RATE` | 2400 | 手动发射速率，解码及接收端需一致 |
| `LEAD` | 1.0 秒 | 手动脚本播放前的静默；另加 0.3 秒尾部静默 |
| `SAVE_RAW` | `true` | 保存不含上述静默的 `v22_tx.raw/.wav` |
| 手动发射幅度 | 0.9 | 脚本的波形缩放，与 GUI 幅度独立 |
| AGC 目标平均幅度 | QPSK：1；16-QAM：约 2.99535 | 按接收速率选择 |
| 静噪门限 | 0.001 | 匹配滤波和抽样后的帧平均幅度门限 |
| 载波环 `Kp` / `Ki` | 0.05 / 0.0002 | 比例与积分增益 |

GUI 默认提前余量 1 秒、尾部余量 2 秒、播放幅度 0.8。采集时长为 `ceil(提前余量 + 完整调制波形时长 + 尾部余量)`；GUI 的等待不是 `v22_emit` 的 `LEAD` 静默，也不改变帧内前导长度。

<a id="实验五参数"></a>
### 实验五参数

| 参数或入口 | 默认值或调用形式 | 行为 |
|---|---|---|
| `sstv_params(mode)` | `'M1'` | 接受模式简称、全名或数值 VIS，返回时序、频率与滤波参数 |
| `sstv_modes()` | 20 项结构体 | 返回简称、名称、VIS、尺寸和扫描参数 |
| `sstv_emit` | 脚本顶部设置 `imageFile`、`MODE='M1'`、`BINARY=true`、`PLAY_AUDIO=true`、`SHOW_FIGURE=true`、`SAVE_FILES=true` | 顺序执行的独立 MATLAB 发送脚本；工作区输出 `x`、`meta`、`P`，默认保存 WAV、PCM 和参考图 |
| `sstv_emit_simulink(imageFile,binary,playAudio,mode)` | 自带图片、`true`、`true`、`'M1'` | 独立的模型仿真入口，保存 WAV、PCM 与参考图，可选播放，无需生成发送 C |
| `sstv_decode` | 脚本顶部 `MAT_FILE='sstvfreq.mat'`、`REFERENCE_FILE='sstv_reference.mat'` | 顺序解码模型输出；参考不存在时仅解图；工作区输出 `result`、`metrics` |
| `P.sync` / `P.porch` / `P.scan` | 4.862 / 0.572 / 146.432 ms | 行同步、间隔、单分量扫描时长 |
| `P.pixel` / `P.line` | 457.6 µs / 446.446 ms | 单像素与整行时长 |
| `P.channelOrder` | `[2 3 1]` | RGB 数组中的 G/B/R 顺序 |
| `P.lowpass` | `fir1(96,1500/(48000/2))` | 97 抽头复基带低通 |
| `P.minimumEnvelope` | `1e-5` | 鉴频前相邻复样本的最低包络 |
| 手动发射幅度 | 0.8 | 与 GUI、系统音量独立；播放另加 1 秒起始静默与 0.3 秒尾部静默 |
| 二值化门限 | 归一化亮度 0.5 | RGB 加权亮度转黑白；关闭则保留彩色 |
| 接收二值判决门限 | RGB 均值 127.5 | 计算有效行二值像素误差率，非信道 BER |

`result` 含 `status`、`message`、`vis`、`mode`、`modeId`、`width`、`height`、`image`、`validRows`、`complete`、`clockPpm` 等字段。`status` 为 `no_vis`、`unsupported_mode`、`no_lines`、`line_timing`、`partial` 或 `ok`；`ok` 只表示该模式全部行均可还原，不表示像素无误。`metrics` 的 `available` 表示参考尺寸匹配且存在可比较行，`mae/psnr` 比较有效行 RGB，`pixelErrors/pixels/pixelErrorRate` 只用于二值图。

以上扫描默认值对应 Martin M1。切换已支持的模式只需选择模式，无需重建模型。修改模式时序时，需同时更新 `sstv_emit.m`、`sstv_decode.m` 内的独立模式表和模型侧参数表，再运行 `build_tx_model` 更新模型；修改接收采样率或滤波参数后需重建接收模型、生成并部署 C。发送端可直接运行 MATLAB 算法或通过 `sim` 仿真，无需发送 C 代码。

<a id="命令行"></a>
## 四、接收程序命令行

五个接收程序的通用调用形式为 `接收程序 -d 输入 -t 秒数 -c 声道数 -r 原始MAT路径`。可执行文件默认位于各实验的 `build/`。

| 选项 | 默认值 | 行为 |
|---|---|---|
| `-d` | `default` | ALSA 后端为设备名；file 后端为 PCM 路径 |
| `-t` | 不限时 | 正数为采集时长；不传时持续到 Ctrl+C 或文件 EOF |
| `-c` | 1 | 采集 1 或 2 声道；不是“选择第几个声道” |
| `-r` | 不保存 | 额外写 `rawAudio` 到指定 MAT 文件 |
| `-h` | — | 显示命令帮助 |
| `-p` | 关闭 | 仅实验一：将采集音频回放到默认播放设备 |
| `-b` | 2400 | 仅实验四：1200 或 2400，设置模型 `RxRate` |

声道行为如下，不能将 `-c 2` 理解为只取左路：

| 实验 | `-c 1` | `-c 2` |
|---|---|---|
| 一至三 | 复制到左右模型输入，模型相加，约为两倍幅度 | 两路去交织后送模型相加，`int16` 饱和 |
| 四、五 | 直接作为单声道模型输入 | 运行时先计算左右平均，再送单声道模型 |

文件后端始终读取单声道 PCM，再复制到所要求的采集声道数，不接受交织双声道文件。正常结束并成功关闭输出文件时退出码为 0；非零退出不能视为完整采集成功。

<a id="模型与文件接口"></a>
## 五、模型与文件接口

### 根级端口

| 实验 | `AudioIn` | 其他输入 | 输出 | 每次处理 |
|---|---|---|---|---|
| 一 | `int16[80,2]`，内存 `[L的80点,R的80点]` | — | `out_f1/out_f2`，各 `double[80]` | 80 点音频 |
| 二 | `int16[160]`，两路各 80 点 | — | `out_data`，double 标量相关值 | 一个码元 |
| 三 | `int16[1600]`，两路各 800 点 | — | `out_data`，double 标量 ±1 判决 | 一个码元 |
| 四 | `int16[960]`，单声道 | `RxRate`，uint16 标量 | `symOut`，`double[120]`，I/Q 交替 | 60 个复符号 |
| 五 | `int16[4800]`，单声道 | — | `frequencyOut`，`double[4800]`，Hz；0 表示低电平不可用 | 4800 个频率值 |

胶水层按 `<模型>_U`、`<模型>_Y` 访问根 I/O。模型端口变化必须同步核对 `src/model_glue.c` 和 `src/model_iface.h`。实验三的多速率调用关系见[实验三原理](实验三_chirp扩频.md#多速率模型如何落到板上)。

### 接收输出 MAT

运行时使用 `common/src/mat_sink.c` 写 MAT v4。结果落在**启动接收程序时的工作目录**，不一定是可执行文件目录；同名文件会被覆盖。下表的 N 为接收机写入的帧数。

| 实验 | 文件 | 变量 | 形状与内容 |
|---|---|---|---|
| 一 | `single_f.mat` | `toFileData` | 81×N，首行帧时间，其余 80 行滤波输出 |
| 一 | `single_f2.mat` | `toFileData2` | 81×N，首行帧时间，其余 80 行第二路输出 |
| 二 | `dpsk5.mat` | `toFileData5` | 2×N，时间 + 相关值 |
| 三 | `chirp5.mat` | `toFileData5` | 2×N，时间 + 判决值 |
| 四 | `v22sym.mat` | `v22Sym` | 121×N，时间 + `I1,Q1,…,I60,Q60` |
| 五 | `sstvfreq.mat` | `sstvFreq` | 4801×N，时间 + 4800 个逐采样音频频率值 |
| 各实验 `-r` | 指定的 `.mat` | `rawAudio` | 无时间行，依次为 80×N、80×N、800×N、960×N、4800×N |

实验一至三的 `rawAudio` 是左右路用 double 相加的未滤波数据，单声道输入会放大为两倍；它保留求和结果，不执行模型中的 `int16` 饱和。实验四、五保存的是合并声道后的单声道 PCM 值。这些“原始 MAT”不是 WAV，也不是可以直接交给 file 后端的 `.raw` 文件。

读取实验四符号的完整示例，在 **MATLAB / 实验四目录**执行：

```matlab
S = load('v22sym.mat');
assert(size(S.v22Sym,1) == 121);
IQ = S.v22Sym(2:end,:);
z = complex(IQ(1:2:end,:), IQ(2:2:end,:));
z = z(:);
fprintf('接收 %d 个符号\n', numel(z));
```

预期符号数量为 `60 × N`。实验一运行 `single_fre_decode`，默认读取 `raw.mat` 的 `rawAudio`；分析模型输出时，将脚本顶部改为 `MAT_FILE='single_f.mat'`、`MAT_VARIABLE='toFileData'`。

### 文件后端 PCM

| 属性 | 要求 |
|---|---|
| 文件头 | 无；不能直接传入 WAV |
| 样本 | 有符号 int16，按运行主机字节序读取；常用平台为小端 S16_LE |
| 声道 | 单声道 |
| 采样率 | 实验一至三 8000 Hz；实验四 9600 Hz；实验五 48000 Hz；后端不检测也不转换采样率 |
| 文件尾 | 最后一帧不足时补零；不足一个 int16 的残缺字节报告错误 |

| `src/main.c` | 采集、声道整理、模型调用、输出写盘与退出处理 |

MATLAB 图片收发脚本按自身所在目录定位结果和图片。板上接收程序将 MAT 文件写入运行时的当前目录；取回到对应实验目录后，再运行 MATLAB 解码脚本。离线输入方式见[文件回放](构建与部署.md#文件回放)。

### 实验四内部文件

| 位置 | 文件与用途 |
|---|---|
| 根目录 | `v22_emit.m` 发射、`v22_decode.m` 解板上符号；两者均为独立单文件 |
| 根目录 | `gui.m` 与收发 `.slx` 模型 |
| `tools/` | `build_model.m`、`build_tx_model.m`：重建收发模型 |
| `gui_support/` | `v22_mod.m`、`v22_modulate.m`：选择发送实现并收集波形 |
| `lib/` | `v22_params.m`：GUI 与模型分支参数 |
| `model/` | `downconvert.m`、`timing_recovery.m`、`agc_squelch.m`、`carrier_recovery.m`：MATLAB Function 块源代码 |
| `model/tx_*.m` | 发送模型的组帧外层、扰码、映射、插零与上变频模块 |
| `model/layout.json` | 模块位置、注释位置和连线路径，重建模型时复用 |
| `lib/` | `v22_img2payload/v22_payload2img`：图片与载荷转换 |
| `lib/` | `v22_pack/v22_unpack/v22_crc16`：HDLC、位填充与 FCS |
| `lib/` | `v22_diagnose`：接收阶段诊断、有效图片筛选；`v22_measure/v22_msequence`：独立定位与实验 BER |
| `lib/` | `v22_symbols_to_bits`：符号判决、差分解码和解扰 |

GUI 自动加入所需辅助目录；独立解码文件自带局部函数，不依赖这些目录。手动调用工具或库函数时，在实验根目录分别运行 `addpath('tools')` 或 `addpath('lib')`；`model/` 由建模脚本读取，不加入搜索路径。

`v22_decode.m` 自带判决、解扰、m 序列、HDLC、FCS 和 BER 局部函数。上述 `lib/` 同名算法供 GUI 或模型分支使用，修改协议时需分别更新并核对一致性。

### 实验五内部文件

| 位置 | 文件与用途 |
|---|---|
| 根目录 | `sstv_emit.m`：独立 MATLAB 发送脚本；`sstv_decode.m`：独立模型输出解码脚本 |
| 根目录 | `gui.m`：直接打开实验界面 |
| `tools/` | `build_model.m`、`build_tx_model.m`：模型构建 |
| `lib/` | `sstv_modes.m`、`sstv_params.m`：GUI 与模型分支的模式表及参数 |
| `gui_support/` | `sstv_modulate.m`：按所选发送机返回波形；`sstv_emit_simulink.m`：命令行模型仿真、保存和播放入口 |
| `model/` | `downconvert.m`、`frequency_discriminator.m`：下变频、相位差鉴频块源代码 |
| `lib/` | `sstv_prepare_image.m`、`sstv_simulate_transmitter.m`：模型分支图片处理和模型仿真 |
| `lib/` | `sstv_decode_frequency.m`：VIS/行同步与图像恢复 |
| `lib/` | `sstv_scan_segments.m`、`sstv_color.m`：模式扫描段与颜色转换 |
| 根目录 | `sstv_transmit.slx`、`sstv_transmit.sldd`：发送模型及其总线类型字典，需一起保留 |
| `model/` | `tx_*.m`：发送模型的时序、寻址、像素读取、颜色编码、色差平均、频率映射与相位累加；正弦输出使用 Simulink 标准模块 |
| `lib/` | `sstv_metrics.m`：只对有效行比较 MAE、PSNR 与二值像素误差 |

`sstv_decode.m` 自带模式表、VIS 检查、行同步、颜色恢复与图像质量计算；无需复制 `lib/`。其输入是接收模型输出的频率 MAT，而不是原始音频。
