# 接口与参数参考

本页集中列出四个实验的环境、入口、参数和数据格式。操作流程见[部署运行教程](手把手部署运行教程.md)与[构建与部署](构建与部署.md)，算法含义见[实验原理索引](README.md#按任务查文档)。

<a id="软件与版本"></a>
## 一、软件与版本

| 环节 | 软件与依赖 | 边界 |
|---|---|---|
| PC 编辑模型、生成 C | MATLAB、Simulink、Simulink Coder、Embedded Coder | 使用 `ert.tlc`；不需要板卡硬件支持包 |
| 模型信号处理 | 对应版本的 DSP System Toolbox 等模型块依赖 | 由实际模型块、滤波器对象和安装版本决定 |
| 状态机及模型构建 | Stateflow 相关功能 | 实验三含 Stateflow 图；实验四建模脚本使用 MATLAB Function 块代码接口 |
| MATLAB 波形成形、重采样与滤波 | Signal Processing Toolbox 等对应函数产品 | R2025b 下实验四入口的静态依赖分析列出 Signal Processing Toolbox；静态扫描不能替代模型许可检查 |
| 板上真实采集构建 | C 编译器、make、ALSA 开发库 | Linux 本机编译，运行时链接 ALSA 等系统库 |
| 板上文件回放或桩模型 | C 编译器、make | 不链接 ALSA；真实模型仍需要生成 C |
| 实验二、三 Python 发射/解码 | Python 3 标准库 | 不代替 Simulink 代码生成，也不包含真实接收模型 |
| GUI 连接板子 | MATLAB 中的 Java/SSH 功能、板上 SSH 服务 | 使用账号密码，不依赖系统 scp 或 ssh 密钥 |

MATLAB 产品归属可能随版本变化；`ver` 可查看安装列表，实际打开模型与代码生成的诊断还会指出缺失的块库或许可。完整生成流程以成功产出 C 为准，不能把“仅安装 MATLAB”视为全部前提。

| 模型 | 保存格式与验证边界 |
|---|---|
| 实验一至三 | 仓库模型采用 R2022a 文件格式，已在 R2025b 打开并生成代码；未以实际 R2022a 环境验证完整生成链 |
| 实验四 | 使用 R2025b 构建；未验证导出到 R2022a 后的兼容性 |

能打开模型不等于生成接口与数值行为完全兼容。跨版本修改后的导出和验证见[版本排障](Q&A.md#模型版本)。

### 图片与真值

| 实验 | 自带图片（宽×高） | 解码所需信息 |
|---|---|---|
| 二、四 | `ren512b/da512b/lan512b/ru512b/yi512b.bmp`：32×16；`lzu2048b.bmp`：64×32 | 二用 BMP 尺寸及发送真值；四从载荷恢复尺寸，BMP 仅作 BER 对照 |
| 三 | `ren128b.bmp`：16×8；`lan336.bmp`：21×16；`ren512b.bmp`：32×16；`lzu2048b.bmp`：64×32 | BMP 尺寸及发送真值 |

图片位于 `baseband_images/`，使用单通道二值 BMP；实验四明确检查像素为 0/1，宽、高均不超过 255。各实验均按列优先展开像素。

实验二、三的 MATLAB 发射端写 `info_all.mat`，解码端用它计算 BER；Python 解码端直接读取给定 BMP 作真值。不能混用另一轮发送的真值文件。

### 实验四参数

| 参数 | 默认值或可选值 | 用途 |
|---|---|---|
| `v22_params(rate)` | `2400`（默认）或 `1200` | 返回收发与建模参数 |
| `P.bps` | 4 或 2 | 每符号比特数 |
| `P.sps` | 16 | 每符号采样点 |
| `P.beta` / `P.span` | 0.75 / 8 | RRC 滚降 / 符号跨度，共 129 抽头 |
| `P.preambleSyms` / `P.postambleSyms` | 300 / 120 | 协议前导 / 后导符号数 |
| `P.scrTaps` / `P.scrLen` | `[14 17]` / 17 | 自同步扰码器 |
| `P.syncBits` | 127 位 m 序列 | HDLC 帧前后各一段，独立定位实验 BER 窗口 |
| `P.syncGuard` | 17 bit | HDLC 与每段 m 序列之间的全 1 保护位 |
| `P.syncMaxErrors` | 25 bit | 每段标记最多容许错误数，还要求间距匹配、窗口唯一 |
| `v22_emit.m` 的 `RATE` | 2400 | 手动发射速率，解码及接收端需一致 |
| `LEAD` | 1.0 秒 | 手动脚本播放前的静默；另加 0.3 秒尾部静默 |
| `SAVE_RAW` | `true` | 保存不含上述静默的 `v22_tx.raw/.wav` |
| 手动发射幅度 | 0.9 | 脚本的波形缩放，与 GUI 幅度独立 |
| AGC 目标平均幅度 | QPSK：1；16-QAM：约 2.99535 | 按接收速率选择 |
| 静噪门限 | 0.001 | 匹配滤波和抽样后的帧平均幅度门限 |
| 载波环 `Kp` / `Ki` | 0.05 / 0.0002 | 比例与积分增益 |

GUI 默认提前余量 1 秒、尾部余量 2 秒、播放幅度 0.8。采集时长为 `ceil(提前余量 + 完整调制波形时长 + 尾部余量)`；GUI 的等待不是 `v22_emit` 的 `LEAD` 静默，也不改变帧内前导长度。

<a id="构建开关"></a>
## 三、Makefile 开关

| 参数 | 默认值 | 含义 |
|---|---|---|
| `MODEL` | `real` | `real` 编译生成 C；`mock` 使用桩模型 |
| `AUDIO` | `alsa` | `alsa` 采集设备；`file` 读 PCM；`null` 合成 1 kHz 单音 |
| `MOCK` | 未设置 | 设置后覆盖为 `MODEL=mock AUDIO=null`，常用 `MOCK=1` |
| `BUILD` | `build` | 可执行文件、对象文件及依赖文件目录 |
| `MODEL_DIR` | `<模型名>_ert_rtw` | 真实模型生成源码目录 |
| `CC` | 系统 C 编译器 | 可指定 gcc 或目标工具链；交叉编译还需匹配目标库 |

示例与适用条件见[构建模式](构建与部署.md#构建模式)。指定相同 `BUILD` 才会清理相应目录；`make clean` 不会自动删除其他自定义构建目录。

<a id="命令行"></a>
## 四、接收程序命令行

四个接收程序的通用调用形式为 `接收程序 -d 输入 -t 秒数 -c 声道数 -r 原始MAT路径`。可执行文件默认位于各实验的 `build/`。

| 选项 | 默认值 | 行为 |
|---|---|---|
| `-d` | `default` | ALSA 后端为设备名；file 后端为 PCM 路径 |
| `-t` | 不限时 | 正数为采集时长；不传时持续到 Ctrl+C 或文件 EOF |
| `-c` | 1 | 采集 1 或 2 声道；不是“选择第几个声道” |
| `-r` | 不保存 | 额外写 `rawAudio` 到指定 MAT 文件 |
| `-h` | — | 显示命令帮助 |
| `-p` | 关闭 | 仅实验一：将采集音频回放到默认播放设备 |
| `-b` | 2400 | 仅实验四：1200 或 2400，设置模型 `RxRate` |

声道行为如下，不能将 `-c 2` 理解为只取左路：

| 实验 | `-c 1` | `-c 2` |
|---|---|---|
| 一至三 | 复制到左右模型输入，模型相加，约为两倍幅度 | 两路去交织后送模型相加，`int16` 饱和 |
| 四 | 直接作为单声道模型输入 | 运行时先计算左右平均，再送单声道模型 |

文件后端始终读取单声道 PCM，再复制到所要求的采集声道数，不接受交织双声道文件。正常结束并成功关闭输出文件时退出码为 0；非零退出不能视为完整采集成功。

<a id="模型与文件接口"></a>
## 五、模型与文件接口

### 根级端口

| 实验 | `AudioIn` | 其他输入 | 输出 | 每次处理 |
|---|---|---|---|---|
| 一 | `int16[80,2]`，内存 `[L的80点,R的80点]` | — | `out_f1/out_f2`，各 `double[80]` | 80 点音频 |
| 二 | `int16[160]`，两路各 80 点 | — | `out_data`，double 标量相关值 | 一个码元 |
| 三 | `int16[1600]`，两路各 800 点 | — | `out_data`，double 标量 ±1 判决 | 一个码元 |
| 四 | `int16[960]`，单声道 | `RxRate`，uint16 标量 | `symOut`，`double[120]`，I/Q 交替 | 60 个复符号 |

胶水层按 `<模型>_U`、`<模型>_Y` 访问根 I/O。模型端口变化必须同步核对 `src/model_glue.c` 和 `src/model_iface.h`。实验三的多速率调用关系见[实验三原理](实验三_chirp扩频.md#多速率模型如何落到板上)。

### 接收输出 MAT

运行时使用 `common/src/mat_sink.c` 写 MAT v4。结果落在**启动接收程序时的工作目录**，不一定是可执行文件目录；同名文件会被覆盖。下表的 N 为接收机写入的帧数。

| 实验 | 文件 | 变量 | 形状与内容 |
|---|---|---|---|
| 一 | `single_f.mat` | `toFileData` | 81×N，首行帧时间，其余 80 行滤波输出 |
| 一 | `single_f2.mat` | `toFileData2` | 81×N，首行帧时间，其余 80 行第二路输出 |
| 二 | `dpsk5.mat` | `toFileData5` | 2×N，时间 + 相关值 |
| 三 | `chirp5.mat` | `toFileData5` | 2×N，时间 + 判决值 |
| 四 | `v22sym.mat` | `v22Sym` | 121×N，时间 + `I1,Q1,…,I60,Q60` |
| 各实验 `-r` | 指定的 `.mat` | `rawAudio` | 无时间行，依次为 80×N、80×N、800×N、960×N |

实验一至三的 `rawAudio` 是左右路用 double 相加的未滤波数据，单声道输入会放大为两倍；它保留求和结果，不执行模型中的 `int16` 饱和。实验四保存的是合并声道后的单声道 PCM 值。这些“原始 MAT”不是 WAV，也不是可以直接交给 file 后端的 `.raw` 文件。

读取实验四符号的完整示例，在 **MATLAB / 实验四目录**执行：

```matlab
S = load('v22sym.mat');
assert(size(S.v22Sym,1) == 121);
IQ = S.v22Sym(2:end,:);
z = complex(IQ(1:2:end,:), IQ(2:2:end,:));
z = z(:);
fprintf('接收 %d 个符号\n', numel(z));
```

预期符号数量为 `60 × N`。实验一分析时显式调用 `spectrum('single_f.mat','toFileData')`；`spectrum` 不带参数默认读取 `raw.mat` 的 `rawAudio`。

### 文件后端 PCM

| 属性 | 要求 |
|---|---|
| 文件头 | 无；不能直接传入 WAV |
| 样本 | 有符号 int16，按运行主机字节序读取；常用平台为小端 S16_LE |
| 声道 | 单声道 |
| 采样率 | 实验一至三 8000 Hz；实验四 9600 Hz；后端不检测也不转换采样率 |
| 文件尾 | 最后一帧不足时补零；不足一个 int16 的残缺字节报告错误 |

## 六、目录与入口

```text
portable-acoustic-sdr/
├── documents/             正式文档与模型示意图
├── common/
│   ├── include/           音频和 MAT 写盘接口
│   ├── src/               ALSA / null / file 后端及 MAT v4 写盘
│   └── matlab/+asdr/      GUI、板端连接、显示等公共实现
└── exp*/
    ├── Makefile           板上构建入口
    ├── src/               main.c、model_glue.c、model_iface.h
    ├── *.slx              PC 上的接收模型
    ├── *_ert_rtw/         生成 C，不入库
    ├── build/             本机编译产物，不入库
    └── *.m                MATLAB 日常入口
```

| 文件或目录 | 作用 |
|---|---|
| `src/main.c` | 采集、声道整理、模型调用、输出写盘与退出处理 |
| `src/model_glue.c` | 将通用运行时接口连接到生成模型符号 |
| `src/model_iface.h` | 帧长、采样率和模型函数声明 |
| `gui.m` / `setup_paths.m` | 打开所选实验 GUI / 配置当前实验和公共 MATLAB 路径 |
| `baseband_images/` | 实验二至四的发送 BMP |
| `sample_data/` | 实验二、三随仓库保存的接收样例与对应真值 |
| `exp2_dpsk/py/` | `dpsk_emit.py`、`dpsk_rev.py` |
| `exp3_chirp/py/` | `bok_emit.py`、`bok_rev.py` |
| `exp3_chirp/bok_sim.m` | MATLAB 端到端仿真入口，使用 `ren512b.bmp` |

MATLAB 图片收发脚本按自身所在目录定位结果和图片；Python 发射脚本也向所属实验目录写文件。Python 解码支持 `python3 py/解码脚本.py 图片路径 MAT路径`，第二个参数可指向独立回放目录，完整例子见[文件回放](构建与部署.md#文件回放)。

### 实验四内部文件

| 位置 | 文件与用途 |
|---|---|
| 根目录 | `v22_emit.m` 发射、`v22_rev.m` 解板上符号、`v22_wav_decode.m` 解 WAV、`v22_params.m` 参数 |

| `model/layout.json` | 模块位置、注释位置和连线路径，重建模型时复用 |
| `private/` | `v22_img2payload/v22_payload2img`：图片与载荷转换 |
| `private/` | `v22_pack/v22_unpack/v22_crc16`：HDLC、位填充与 FCS |
| `private/` | `v22_diagnose`：接收阶段诊断、有效图片筛选；`v22_measure/v22_msequence`：独立定位与实验 BER |
| `private/` | `v22_mod/v22_demod`：调制与离线解调；`v22_symbols_to_bits`：符号判决、差分解码和解扰 |

`private/` 由 MATLAB 自动查找，`model/` 由建模脚本读取；不需要把二者加入搜索路径。
